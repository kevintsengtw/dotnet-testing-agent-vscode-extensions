# dotnet Testing Agent v0.7.0-beta.4 安裝指南

> 這是 **prerelease**，用於發佈前的工作流程驗證，不是正式版。正式版請使用 [v0.6.0](https://github.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/releases/tag/v0.6.0)。
>
> 本版移除 GitHub Copilot 模式，只支援 Claude Code 與 Codex。

## 本版重點

修正 Codex 模式下 Unit 測試工作流程的驗收裁決問題。

先前執行 Codex 的 Unit 工作流程時，Reviewer 會完成品質審查並給出評分與建議，但最後的驗收關卡可能判定不通過，訊息指出審查結果缺少必要的裁決欄位。測試本身是產生且通過的，只是流程無法正式結案。

原因是負責審查的 agent 定義中從未提及該欄位，驗證器卻要求它必須有值——要求與說明分處兩地且不一致。本版更新了 Reviewer 的 agent 定義、Unit 工作流程說明與對應驗證器，使其成為明確要求。

Claude 模式，以及 Codex 的 TUnit／Integration／Aspire 工作流程不受此問題影響。

## 下載

從 [v0.7.0-beta.4 Release](https://github.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/releases/tag/v0.7.0-beta.4) 下載：

- `dotnet-testing-agent-0.7.0-beta.4.vsix`

## 安裝或升級

1. 開啟 Extensions 面板（`Ctrl+Shift+X`）。
2. 點選右上角 `...` → **Install from VSIX...**。
3. 選擇 `dotnet-testing-agent-0.7.0-beta.4.vsix`。
4. 完整結束並重新開啟 VS Code；不要只執行 Reload Window。

命令列安裝：

```bash
code --install-extension dotnet-testing-agent-0.7.0-beta.4.vsix
```

**從 v0.7.0-beta.3 升級**：本版更新了 Codex 的工作流程內容，安裝後請開啟 **Codex 模式**面板執行「更新／修復 Codex」，讓工作區取得修正後的內容。Claude 模式內容未變更，不需重新部署。

更新完成後，版本資訊面板的「Codex 工作流程」該列應顯示 `beta/agent-modes (68c68252)` 且狀態為「✓ 已套用」。

**從 v0.6.0 升級前請注意**：本版變更了共用 Skills 的安裝位置，且移除 Copilot 模式。建議先在非正式的工作區驗證，確認四種測試工作流程可正常運作後，再套用到日常使用的專案。

## 更新後確認

- 從 Activity Bar 開啟「dotnet-testing-agent 工具包」。
- 「測試工作流程內容」四列應皆顯示「✓ 已套用」。
- 對使用中的模式執行**環境診斷**，其結論應與面板顯示一致。
