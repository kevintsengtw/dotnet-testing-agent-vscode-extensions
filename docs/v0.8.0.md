# dotnet Testing Agent v0.8.0 安裝指南

v0.8.0 新增 Claude Lite、Codex Lite，並為 Codex Full／Lite 提供逐 Agent 的模型與推理強度設定。Full 與 Lite 可以同時安裝；切換側邊欄中的查看模式不會修改工作區。

## 內建正式版本

| 內容 | 來源版本 |
| --- | --- |
| Shared Skills | `v2.4.2` |
| unit-test-scenarios | `d0050198` 精確 commit |
| Claude Full orchestration | `v1.5.0` |
| Claude Lite orchestration | `v1.0.0` |
| Codex Full orchestration | `v1.2.1` |
| Codex Lite orchestration | `v1.0.0` |

每個來源都來自公開 repository。Extension 會先把 stable tag 解析為 exact commit，再以固定來源計畫完成下載、驗證與部署；無法取得線上來源時，乾淨安裝仍可使用 VSIX 內完整的 bundled snapshot。

## 前置需求

| 項目 | 最低版本 |
| --- | --- |
| VS Code | 1.85.0 |
| Node.js | 18.0.0 |
| 作業系統 | Windows 10/11；macOS / Linux 依既有支援範圍 |

依使用模式準備 Claude Code 或 Codex。Integration／Aspire 容器測試另需 Docker。

## 下載

從 [v0.8.0 Release](https://github.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/releases/tag/v0.8.0) 下載：

- `dotnet-testing-agent-0.8.0.vsix`

## 安裝或升級

1. 開啟 Extensions 面板（`Ctrl+Shift+X`）。
2. 點選右上角 `...` → **Install from VSIX...**。
3. 選擇 `dotnet-testing-agent-0.8.0.vsix`。
4. 完整結束並重新開啟 VS Code；不要只執行 Reload Window。

命令列安裝：

```bash
code --install-extension dotnet-testing-agent-0.8.0.vsix
```

### 從 v0.7.0 升級

- 開啟實際使用的 Claude 或 Codex 面板，查看 Full 的來源與安裝狀態。
- 依面板提供的操作執行更新或重新初始化，再執行環境診斷。
- v0.7.0 Codex Full 的正式 managed assets 會先通過 exact-source reconciliation；若檔案已被使用者修改或來源證據不符，操作會停止而不覆寫。
- Lite 不會自動安裝；需要時再個別安裝 Claude Lite 或 Codex Lite。
- Shared Skills 會隨已授權的模式安裝／更新交易升級至內建 v2.4.2，未知的自訂 Skills 仍會保留。

## 本版重點

- Claude Full、Claude Lite、Codex Full、Codex Lite 可並存，並以中央 manifest 管理 ownership 與 shared reference counting。
- 目前查看的 Full／Lite 按鍵使用實心樣式及「✓ 目前」；每個模式是否已安裝另行顯示，不必靠顏色猜測。
- Codex Agents 分頁在每張 Agent 卡片直接顯示資產狀態、來源預設、目前模型、模型與推理強度下拉選單。
- Codex 設定先產生唯讀變更預覽，再由 VS Code 原生確認；可以只套用或重設一個 Agent。
- 每次部署使用固定 stable tag 與 exact commit，並在同一交易內完成寫入與 rollback；不會以 moving `latest` 或部分 online／bundled 混合內容更新工作區。
- Doctor 可診斷 managed hash drift、缺檔、混合版本、來源衝突、legacy shared path、Codex override metadata 與使用者設定問題。
- Shared Skills 和四個工作流程來源的更新通知提供「查看 Release」、「稍後」與「忽略此版本」；Shared Skills 不會被通知機制靜默更新。

## Codex Agent 模型設定

支援模型：

- GPT-5.6 Sol
- GPT-5.6 Terra
- GPT-5.6 Luna

支援推理強度：Low、Medium、High、XHigh、Max。

![Codex Lite 的 Agent 資產狀態與模型設定集中在同一卡片](https://raw.githubusercontent.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/master/images/v0.8.0-codex-lite-agent-settings.png)

每張 Agent 卡片會同時顯示資產是否存在、來源預設、目前 model／effort、兩個下拉選單，以及單一 Agent 的預覽套用／重設。受管理路徑與 exact source 位於預設收合的「Agent 技術資訊」。Codex Full 的 16 個 Agents 依 Aspire、Integration、TUnit、Unit 分組；Codex Lite 顯示兩個 Unit Agents。

### 套用 model／effort

1. 在指定 Agent 卡片選擇模型與推理強度。
2. 點選「預覽套用」。Extension 只計算變更，不會在預覽階段寫入工作區。
3. 檢查受影響 Agent 數量及 before／after tuple。
4. 點選「繼續並由 VS Code 確認」，再於 VS Code 原生確認視窗核准。
5. 套用成功後執行 **Developer: Reload Window**。
6. Reload 完成後建立新的 Codex task。這項契約不宣稱已經執行中的 task 會 hot reload，也不會中斷目前 task。

![單一 Codex Agent 的唯讀變更預覽](https://raw.githubusercontent.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/master/images/v0.8.0-codex-agent-preview.png)

若要回復來源預設，請對指定 Agent 使用「預覽重設」，檢查預覽後再確認。Full 與 Lite 的 override metadata、設定與重設範圍互相隔離。

![Codex Full 的 Unit Agents 分組與逐 Agent 設定](https://raw.githubusercontent.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/master/images/v0.8.0-codex-full-unit-agents.png)

## 更新通知

Extension 會在啟動及完成安裝／更新操作後，檢查 Shared Skills、Claude Full、Claude Lite、Codex Full、Codex Lite 的最新 stable Release。通知提供：

- **查看 Release**：開啟對應的 allowlisted Release 頁面；Shared Skills 不會因此進入部署流程。
- **稍後**：本次不處理，不記錄忽略狀態。
- **忽略此版本**：只忽略指定來源、repository 與 stable tag；後續新版本仍會再次通知。

通知不會靜默更新工作區。真正的安裝或更新仍必須由使用者明確操作，並經過完整 preflight、integrity 與 transaction 檢查。

## 更新後確認

- 從 Activity Bar 開啟「dotnet-testing-agent 工具包」。
- 確認需要的 Full／Lite 模式顯示「已安裝」，目前查看的模式另有「✓ 目前」。
- 對每個實際使用的模式執行「環境診斷」。
- 版本資訊應顯示 Shared Skills `v2.4.2`、Claude Full `v1.5.0`、Claude Lite `v1.0.0`、Codex Full `v1.2.1`、Codex Lite `v1.0.0`。
- 若調整 Codex Agent 模型，先檢查 preview，再確認套用；Reload Window 後以新 task 驗證設定。
- 完整重啟 Claude Code 或 Codex，再執行所需的 Unit、TUnit、Integration 或 Aspire 工作流程。

完整變更請見 [CHANGELOG](https://github.com/kevintsengtw/dotnet-testing-vscode-extensions/blob/master/CHANGELOG.md)。
