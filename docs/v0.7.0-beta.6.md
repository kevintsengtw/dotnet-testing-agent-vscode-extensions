# dotnet Testing Agent v0.7.0-beta.6 安裝指南

> 這是 **prerelease**，用於發佈前的工作流程驗證，不是正式版。正式版請使用 [v0.6.0](https://github.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/releases/tag/v0.6.0)。
>
> 本版移除 GitHub Copilot 模式，只支援 Claude Code 與 Codex。

## 本版重點

**Claude 的整合測試工作流程不再遺漏收尾清理。**

四種工作流程都會在測試專案下建立一個暫存目錄，存放各階段之間的交接檔案，流程結束時清除。整合測試工作流程先前會在產出結果後直接結束，跳過這個步驟，暫存檔案因此留在測試專案裡。

四種工作流程在這一段的說明文字完全相同，只有整合測試會跳過。本版改為要求流程結束時輸出一行清理狀態——沒有這一行就代表流程未走完。同一份說明中，被標記為必須輸出的用量統計表格從未被遺漏，而只被列為必要動作、沒有輸出要求的清理步驟則會被跳過；本版讓兩者受同樣的約束。

**清理方式改為跨平台可靠的作法。**

先前使用的刪除指令在 Windows 路徑下可能在解析階段就失敗，指令根本不會執行，原本準備的備援機制也攔不到這種情形。本版改用不受此影響的方式，並在回報完成前先確認目錄確實消失；若未消失，會明確回報清理未完成並列出殘留內容，不會宣告成功。

這兩項都不影響測試的產出與品質，只影響流程收尾是否乾淨、以及失敗時是否看得見。

## 下載

從 [v0.7.0-beta.6 Release](https://github.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/releases/tag/v0.7.0-beta.6) 下載：

- `dotnet-testing-agent-0.7.0-beta.6.vsix`

## 安裝或升級

1. 開啟 Extensions 面板（`Ctrl+Shift+X`）。
2. 點選右上角 `...` → **Install from VSIX...**。
3. 選擇 `dotnet-testing-agent-0.7.0-beta.6.vsix`。
4. 完整結束並重新開啟 VS Code；不要只執行 Reload Window。

命令列安裝：

```bash
code --install-extension dotnet-testing-agent-0.7.0-beta.6.vsix
```

**從 v0.7.0-beta.5 升級**：本版只變更 Claude 模式的工作流程內容。安裝後請開啟 **Claude 模式**面板執行「更新／修復 Claude」。Codex 模式內容未變更，不需重新部署。

更新完成後，版本資訊面板的「Claude 工作流程」該列應顯示 `beta/agent-modes (3ae94c50)` 且狀態為「✓ 已套用」。

**從 v0.6.0 升級前請注意**：本版變更了共用 Skills 的安裝位置，且移除 Copilot 模式。建議先在非正式的工作區驗證，確認四種測試工作流程可正常運作後，再套用到日常使用的專案。

## 更新後確認

- 從 Activity Bar 開啟「dotnet-testing-agent 工具包」。
- 「測試工作流程內容」四列應皆顯示「✓ 已套用」。
- 對使用中的模式執行**環境診斷**，其結論應與面板顯示一致。
- 執行任一 Claude 測試工作流程，回覆的最後一行應出現清理狀態。
