# dotnet Testing Agent v0.7.0-beta.3 安裝指南

> 這是 **prerelease**，用於發佈前的工作流程驗證，不是正式版。正式版請使用 [v0.6.0](https://github.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/releases/tag/v0.6.0)。
>
> 本版移除 GitHub Copilot 模式，只支援 Claude Code 與 Codex。

## 本版重點

修正版本資訊面板的三個問題，讓你能清楚知道目前用的是哪個版本的測試工作流程內容。

**面板不再誤報。** 先前只要 extension 版本號更新，兩個模式都會顯示部署落差並要求重新初始化——即使該模式的工作流程內容根本沒變。現在改用與環境診斷相同的驗證，只有內容真的不一致才提示。

**新增「測試工作流程內容」區塊。** 恆常顯示四列：共用技術 Skills、unit-test-scenarios、Claude 工作流程、Codex 工作流程。每列顯示 extension 內建的版本與工作區的實際狀態，一致時顯示「✓ 已套用」，不一致時顯示工作區的版本與更新按鈕。先前面板只講 extension 版本號，看不出工作流程內容的版本。

**共用 Skills 終於可見。** `.agents/skills` 的部署狀態先前完全不在面板中顯示。

**prerelease 更新通知。** 先前安裝 beta 版時，面板會顯示「最新版本 v0.6.0 ✓ 已是最新」並附上舊版說明——因為查詢的端點會排除 prerelease。現在安裝 beta 版即可收到新 beta 與新正式版的通知；安裝正式版者不受影響，不會被測試版打擾。

## 下載

從 [v0.7.0-beta.3 Release](https://github.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/releases/tag/v0.7.0-beta.3) 下載：

- `dotnet-testing-agent-0.7.0-beta.3.vsix`

## 安裝或升級

1. 開啟 Extensions 面板（`Ctrl+Shift+X`）。
2. 點選右上角 `...` → **Install from VSIX...**。
3. 選擇 `dotnet-testing-agent-0.7.0-beta.3.vsix`。
4. 完整結束並重新開啟 VS Code；不要只執行 Reload Window。

命令列安裝：

```bash
code --install-extension dotnet-testing-agent-0.7.0-beta.3.vsix
```

**從 v0.7.0-beta.2 升級**：工作流程內容未變更，**不需要重新初始化任何模式**。若先前依 beta.2 的提示重新初始化過 Codex，面板現在應顯示四列皆為「✓ 已套用」。

**從 v0.6.0 升級前請注意**：本版變更了共用 Skills 的安裝位置，且移除 Copilot 模式。建議先在非正式的工作區驗證，確認四種測試工作流程可正常運作後，再套用到日常使用的專案。

## 更新後確認

- 從 Activity Bar 開啟「dotnet-testing-agent 工具包」。
- 「測試工作流程內容」區塊應顯示四列，各自標明版本與狀態。
- 對使用中的模式執行**環境診斷**，其結論應與面板顯示一致。
