# dotnet Testing Agent v0.7.0 安裝指南

> v0.7.0 只支援 Claude Code 與 Codex，並將兩種模式更新至已正式發佈的工作流程版本。GitHub Copilot 模式、local RAG 與 MCP provider 已移除。

## 內建正式版本

| 內容 | 來源版本 |
| --- | --- |
| Shared Skills | `v2.4.1` |
| unit-test-scenarios | `d0050198` 精確 commit |
| Claude orchestration | `v1.5.0` |
| Codex orchestration | `v1.2.0` |

所有來源都來自公開 repository，並以精確 commit 鎖定於 VSIX；初始化不會在背景改抓 moving `latest`。

## 前置需求

| 項目 | 最低版本 |
| --- | --- |
| VS Code | 1.85.0 |
| Node.js | 18.0.0 |
| 作業系統 | Windows 10/11；macOS / Linux 依既有支援範圍 |

依使用模式準備 Claude Code 或 Codex。Integration／Aspire 容器測試另需 Docker。

## 下載

從 [v0.7.0 Release](https://github.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/releases/tag/v0.7.0) 下載：

- `dotnet-testing-agent-0.7.0.vsix`

## 安裝或升級

1. 開啟 Extensions 面板（`Ctrl+Shift+X`）。
2. 點選右上角 `...` → **Install from VSIX...**。
3. 選擇 `dotnet-testing-agent-0.7.0.vsix`。
4. 完整結束並重新開啟 VS Code；不要只執行 Reload Window。

命令列安裝：

```bash
code --install-extension dotnet-testing-agent-0.7.0.vsix
```

### 從 v0.6.0 升級

- v0.7.0 不再提供 GitHub Copilot 模式。既有 `.github/` 自訂內容不會被 Extension 刪除，但也不再由 Extension 管理。
- 共用 Skills 改放在 `.agents/skills/`；Claude／Codex 模式目錄只保留各自專屬資產。
- 安裝後請對實際使用的 Claude、Codex 模式各執行一次「初始化」或「更新／修復」，再執行環境診斷。

### 從 v0.7.0 beta 升級

Claude 與 Codex 的 manifest 都會由 beta 快照切換為 stable 正式快照；Codex `v1.2.0` 同時更新完整 runtime validator 集合。請對實際使用的每個模式各執行一次「更新／修復」。

## 本版重點

- 共用技術 Skills 與 `unit-test-scenarios` 統一部署至 `.agents/skills/`，可同時供 Claude Code 與 Codex 使用。
- Claude／Codex 專屬 Skills、Agents、scripts 與設定各自保留在 `.claude/`、`.codex/`。
- 初始化與更新採原子交易：任一步驟失敗即還原原有內容，並保留未知的使用者自訂檔案。
- Doctor 可偵測缺檔、內容 hash 漂移、混合版本、舊共用 Skill 殘留與 manifest 不一致。
- 版本資訊面板直接顯示 Shared Skills、unit-test-scenarios、Claude 與 Codex 四項內容狀態。

## 更新後確認

- 從 Activity Bar 開啟「dotnet-testing-agent 工具包」。
- 對使用中的每個模式執行「環境診斷」，確認所有必要項目通過。
- 「測試工作流程內容」應顯示 Claude `v1.5.0`、Codex `v1.2.0`，且工作區狀態為「✓ 已套用」。
- 完整重啟 Claude Code 或 Codex 後，再執行所需的 Unit、TUnit、Integration 或 Aspire 工作流程。

完整變更請見 [CHANGELOG](https://github.com/kevintsengtw/dotnet-testing-vscode-extensions/blob/master/CHANGELOG.md)。
