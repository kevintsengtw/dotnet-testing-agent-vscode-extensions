# dotnet Testing Agent v0.7.0-beta.1 安裝指南

> 這是 **prerelease**，用於發佈前的工作流程驗證，不是正式版。正式版請使用 [v0.6.0](https://github.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/releases/tag/v0.6.0)。
>
> 本版移除 GitHub Copilot 模式，只支援 Claude Code 與 Codex。

| 項目 | 最低版本 |
| --- | --- |
| VS Code | 1.85.0 |
| Node.js | 18.0.0 |

## 下載

從 [v0.7.0-beta.1 Release](https://github.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/releases/tag/v0.7.0-beta.1) 下載：

- `dotnet-testing-agent-0.7.0-beta.1.vsix`

## 安裝或升級

1. 開啟 Extensions 面板（`Ctrl+Shift+X`）。
2. 點選右上角 `...` → **Install from VSIX...**。
3. 選擇 `dotnet-testing-agent-0.7.0-beta.1.vsix`。
4. 完整結束並重新開啟 VS Code；不要只執行 Reload Window。

命令列安裝：

```bash
code --install-extension dotnet-testing-agent-0.7.0-beta.1.vsix
```

**從 v0.6.0 升級前請注意**：本版變更了共用 Skills 的安裝位置，且移除 Copilot 模式。建議先在非正式的工作區驗證，確認四種測試工作流程可正常運作後，再套用到日常使用的專案。

## 本版重點

- **共用技術 Skills 改安裝到 `.agents/skills`**；`.claude/skills` 與 `.codex/skills` 只保留該模式專屬的五個 Skills。
- **移除 GitHub Copilot 模式**，連同 local RAG、MCP provider、`.github/skills` 與 `.github/agents` 一併移除。
- **初始化採完整交易**：任一步失敗會整套 rollback，不會留下混合版本；已初始化的模式，同一個入口變成「更新／修復」。
- **保留使用者自訂內容**：`.agents/skills` 下不屬於受管理清單的 Skills 會被保留；更新只移除新版已淘汰的受管理檔案。
- **Doctor 診斷加強**：同時驗證檔案雜湊、資產清單、快照版本與受管理檔案清單，任一項不符會明確失敗。
- **`unit-test-scenarios` 改由獨立公開 repository 供應**，以鎖定 commit 取得。
- **同步來源全面公開化**：orchestration 內容改由公開 repository 的 `beta/agent-modes` 分支供應，先前指向私有 repository。

## 更新後確認

- 從 Activity Bar 開啟「dotnet-testing-agent 工具包」。
- 對使用中的模式執行**環境診斷**，確認全部通過。
- 在實際專案上跑一次測試工作流程（Unit、TUnit、Integration 或 Aspire），確認 Agent 能正確找到 `.agents/skills` 下的 Skills。
