# v0.7.0-beta.1 開發驗證指南

此版本為 **prerelease**，不是正式 Release，而是 Claude Code 與 Codex 新目錄契約的候選驗證版。

## 相對於 v0.7.0-alpha 的關鍵變更

**orchestration 同步來源全面公開化。** 先前 `bundled/` 的兩個 orchestration 來源指向私有 lab repository，導致只有具備 lab 存取權的人能重建 `bundled/`。本版改為指向公開 repository 的 `beta/agent-modes` 分支 exact commit：

| 來源 | Repository | Ref |
|---|---|---|
| claudeOrchestration | `dotnet-testing-agent-orchestration-claude` | `beta/agent-modes` |
| codexOrchestration | `dotnet-testing-agent-orchestration-codex` | `beta/agent-modes` |
| sharedSkills | `dotnet-testing-agent-skills` | `v2.4.1` |
| unitTestScenarios | `unit-test-scenarios` | `main` |

四個來源自此全部公開，任何人 clone 本 repository 都能執行 `npm run sync-bundled` 重建並以 `npm run verify-bundled` 驗證雜湊。

相關的一致性調整：

- `bundled/alpha-source-lock.json` 更名為 `bundled/source-lock.json`，`scripts/sync-bundled-alpha.mjs` 更名為 `scripts/sync-bundled.mjs`。發佈頻道改由 lock 檔內的 `channel` 欄位表達，未來轉正式版不需再改檔名。
- `npm run sync-bundled-alpha` 別名移除，統一為 `npm run sync-bundled`。
- 各元件的 `version` 前綴改由頻道常數決定（`beta-<commit12>`），與 `channel` 欄位不再可能不同步。

## 沿用 v0.7.0-alpha 的變更

- 移除 GitHub Copilot、RAG 與 MCP 功能。
- 共用技術 Skills 安裝到 `.agents/skills`。
- `unit-test-scenarios` 從獨立公開 repository 的鎖定 commit 取得。
- Claude／Codex 專屬 Skills 分別保留在 `.claude/skills`、`.codex/skills`。
- 模式初始化採完整交易、integrity 驗證與失敗 rollback。
- 同一入口在初始化後提供「更新／修復」，Doctor 同時驗證 hash、asset-set、snapshot version 與 managed-file manifest。

## 必測矩陣

| Workspace | Claude | Codex |
|---|---:|---:|
| 全新、沒有 `.agents/skills` | 初始化、Doctor、四流程 | 初始化、Doctor、四流程 |
| 已有 `.agents/skills` 與自訂 Skill | 保留並更新 managed Skills | 保留並更新 managed Skills |
| 從 v0.6.0 升級、有舊共用副本 | 清除舊 managed 副本、保留未知檔 | 清除舊 managed 副本、保留未知檔 |
| 任一 managed file 被修改或缺少 | Doctor 明確失敗 | Doctor 明確失敗 |
| 無效 settings/config | 中止並 rollback | 中止並 rollback |

四流程是 Unit、TUnit、Integration、Aspire。除初始化與 Doctor 外，需確認 Agent 能實際發現 `.agents/skills` 並完成 workflow contract。

## 自動檢查

```powershell
npm run verify-bundled
npm run check-types
npm run lint -- --max-warnings 0
npm test
npm run verify-package
npm run package -- --out dotnet-testing-agent-0.7.0-beta.1.vsix
```

有桌面環境時另執行 `npm run test:vscode`。

要重建 `bundled/` 時執行 `npm run sync-bundled`。注意 `dotnet-testing-agent-skills` 約 103 MB，`--depth 1` fetch 在一般網路下需數分鐘。

## 禁止發布條件

- bundled lock 或 integrity 不一致。
- 初始化留下 shared/mode 混合版本。
- 使用者自訂檔案被移除。
- Doctor、rollback 或任一必要 workflow smoke test 失敗。
- 上游 lab workflow 本身仍存在互相衝突的硬性契約。

先前 Codex Unit 的 pre-Analyzer 契約衝突已由上游修正。`bundled/known-upstream-issues.json` 目前為空；若未來偵測到新的 release-blocking 契約，仍須停止發布。
