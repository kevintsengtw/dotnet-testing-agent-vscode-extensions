# dotnet Testing Agent v0.7.0-beta.2 安裝指南

> 這是 **prerelease**，用於發佈前的工作流程驗證，不是正式版。正式版請使用 [v0.6.0](https://github.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/releases/tag/v0.6.0)。
>
> 本版移除 GitHub Copilot 模式，只支援 Claude Code 與 Codex。

## 本版重點

修正 Codex 四種測試工作流程的 Analyzer 階段耗時統計缺失。

v0.7.0-beta.1 使用 Codex 模式時，工作流程報告的「階段 1 Analyzer」耗時會顯示為未提供，並標示 `timing evidence incomplete`，導致總耗時無法完整計算。測試結果本身不受影響（測試仍會正確產生並執行），只是耗時與 profiling 報告不完整。

本版更新 Codex orchestration 內容至已修正的版本，Analyzer 階段的時間戳會完整記錄。Claude 模式不受此問題影響，內容未變更。

## 下載

從 [v0.7.0-beta.2 Release](https://github.com/kevintsengtw/dotnet-testing-agent-vscode-extensions/releases/tag/v0.7.0-beta.2) 下載：

- `dotnet-testing-agent-0.7.0-beta.2.vsix`

## 安裝或升級

1. 開啟 Extensions 面板（`Ctrl+Shift+X`）。
2. 點選右上角 `...` → **Install from VSIX...**。
3. 選擇 `dotnet-testing-agent-0.7.0-beta.2.vsix`。
4. 完整結束並重新開啟 VS Code；不要只執行 Reload Window。

命令列安裝：

```bash
code --install-extension dotnet-testing-agent-0.7.0-beta.2.vsix
```

**從 v0.7.0-beta.1 升級**：安裝後開啟 Codex 模式面板，執行「更新／修復 Codex」讓工作區取得修正後的 orchestration 內容。Claude 模式無需重新部署。

**從 v0.6.0 升級前請注意**：本版變更了共用 Skills 的安裝位置，且移除 Copilot 模式。建議先在非正式的工作區驗證，確認四種測試工作流程可正常運作後，再套用到日常使用的專案。

## 更新後確認

- 從 Activity Bar 開啟「dotnet-testing-agent 工具包」。
- 對使用中的模式執行**環境診斷**，確認全部通過。
- Codex 模式使用者可在下次執行測試工作流程時，確認報告中的「階段 1 Analyzer」已有耗時數據。
